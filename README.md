# Basic Patterns in Java

This repository contains some **basic pattern programs** implemented in Java.

## Patterns Included

* Star Patterns
* Number Patterns
* Character Patterns
* Basic Pyramid Patterns
* Other Simple Patterns

## Technologies Used

* Java

## How to Run

1. Clone the repository.
2. Open the required `.java` file.
3. Compile and run the program.

```bash
javac filename.java
java filename
```

## Purpose

This repository was created to practice **nested loops, logic building, and pattern programming in Java**.
